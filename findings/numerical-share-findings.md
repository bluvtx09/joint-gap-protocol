# 수치 오차 몫 — 갭 분해에 네 번째 항을 넣다

2026-09-30. `analysis/numerical_share_check.py`로 재현한다 (약 30초, 하드웨어 불필요).

## 왜

`analyze_gap.py`는 모든 성분을 실측값으로 바꿔도 남는 잔차를 "노이즈 몫"과 "구조 몫"으로 나눴다.
그런데 시뮬레이터 자체의 적분 오차도 잔차에 들어간다. 이 몫은 파라미터도 모델 구조도 아니다.
규칙 4는 "내부 1 ms 이하"라는 고정값으로 이 몫을 무시해 왔다.

같은 재생을 적분 간격 1/2, 1/4로 다시 돌리면 이 몫을 정답 없이 잴 수 있다 (SimDiff의 자기 불일치).
세 가지를 확인했다.

## 발견 1. 수치 오차 추정은 정확하다

정답 파라미터, 명령 전부 기록, 노이즈 없음으로 두면 후보와 참값의 차이는 순수하게 적분 간격 탓이다.
참값은 1/8 ms로 만들었으므로, 추정이 정확하면 실제/추정 = 1 − 1/8 = 0.875가 나와야 한다.

| 관절 강성 | 궤적 | 실제/추정 | 관측 차수 | 1 ms 수치 오차 (기준 갭 대비) |
|---|---|---|---|---|
| low | chirp / slow / stair | 0.87 / 0.87 / 0.87 | 1.00 / 1.00 / 1.00 | 1.0 / 0.5 / 0.6% |
| mid | chirp / slow / stair | 0.87 / 0.87 / 0.87 | 1.02 / 1.01 / 1.00 | 2.0 / 0.8 / 1.5% |
| high | chirp / slow / stair | 0.87 / 0.87 / 0.87 | 1.03 / 1.00 / 1.01 | **8.4** / 1.7 / 4.3% |

9개 조건 전부 이론값과 같았다.

## 발견 2. 1 ms는 충분하다는 보장이 아니다

규칙 4대로 1 ms로 돌려도 뻣뻣한 관절에 빠른 궤적(chirp)을 주면 수치 오차가 기준 갭의 8.4%다.
데모 분해에서는 chirp/high 조건의 수치 오차 몫(11.4%)이 노이즈 몫(2.0%)보다 컸다.
이 몫을 따로 빼지 않으면 전부 "모델 구조 문제"로 보고된다.

규칙 4를 "1 ms 이하로 돌리고, 수치 오차 몫을 재서 보고한다. 노이즈 몫보다 크면 더 줄인다"로 바꿨다.

## 발견 3. 잔차는 빼기가 아니라 제곱합으로 나눠야 한다

잔차는 RMS다. 서로 독립인 오차는 제곱으로 더해진다.

**명령을 전부 기록한 데모 (참 구조 잔차 = 0).** 잔차를 노이즈 몫과 수치 오차 몫으로 다시 만들어 보면,
그냥 더하기는 중앙값 0.82%p 틀리고 제곱합은 0.06%p 틀렸다 (9개 조건).

**200 Hz로 기록한 데모 (규칙 3 위반).** 노이즈를 뺀 같은 데모에서 직접 잰 구조 잔차를 정답으로 두고 비교했다.

| 궤적 / 강성 | 정답 (노이즈 없음) | 옛 방식 (잔차 − 노이즈) | 새 방식 (제곱합) |
|---|---|---|---|
| stair / high | 44.9% | 17.7% | 42.0% |
| slow / high | 20.0% | 4.0% | 19.0% |
| slow / mid | 15.3% | 4.7% | 14.8% |
| chirp / high | 37.4% | 37.1% | 37.3% |

옛 방식은 노이즈가 큰 조건에서 구조 잔차를 최대 27%p 작게 봤다 (9개 조건 중앙값 5.7%p).
새 방식은 최대 2.9%p 안에서 맞았다.
"노이즈가 크니 구조 문제는 작다"는 판정이 옛 방식에서는 틀릴 수 있었다는 뜻이다.

## 바뀐 것

- `analyze_gap.py`: 수치 오차 몫과 관측 차수를 계산해 표와 CSV에 넣었다. 구조 잔차는 제곱합으로 뺀다.
- 데모의 참값을 1/8 ms로 만든다. 예전에는 분석과 같은 1 ms로 만들어 둘이 같은 적분 오차를 공유했고,
  그래서 수치 오차가 갭에 보이지 않았다 (SimDiff에서 "두 엔진이 같은 근사를 쓰면 일치하면서 함께 틀린다"와 같은 현상).
- 데모 최대 구조 잔차는 33% → 42%(stair/high)로 바뀌었다. 규칙 3의 숫자도 고쳤다.
- 규칙 4(수치 오차 측정), 규칙 8(제곱합), 보고 형식을 개정했다.

## 한계
